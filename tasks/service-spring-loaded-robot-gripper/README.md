This folder currently contains an engineering calibration, not a benchmark submission.

The intended candidate is complete service of a leaking spring-loaded pneumatic robot gripper: disassembly with both prescribed preload-restraint stages, replacement of worn seals/parts, reassembly and functional verification. Only the vise transmission component is present. No complete repair, task scorer, successful demonstration or model evaluation exists yet.

The component references the original full-size [NVIDIA SimReady bench vise](https://huggingface.co/datasets/nvidia/simready-assets/tree/9d4556bfe80868c1d27a7a7ba1c2774e63e8cedd/equipment_bench_vise_a01), © NVIDIA, CC-BY 4.0. Its geometry remains unchanged. The base is fixed, swivel locked, gravity enabled, and a reciprocal constraint couples screw and slider using an explicitly estimated 3 mm lead. The handle mass/inertia use its closed source mesh and assumed steel density of 7,850 kg/m³. The probes apply bounded fixture efforts with the robot stationary; they are not robot manipulation demonstrations.

`vise_friction_probe.py` tests an approximate passive screw model using measured axial reaction, estimated mean thread radius 6 mm, and assumed friction coefficient 0.15. The sliding handle has separate guide friction proportional to measured transverse reaction. Both use native static/dynamic friction efforts; no poses or joint positions are fixed during a run. The centered handle is an authored starting configuration with unchanged physical stops. These parameters are reconstruction assumptions, not measurements of this vise. [Roton's screw mechanics reference](https://www.roton.com/screw-university/screw-actions/screw-backdriving-efficiency/) explains self-locking and gives an illustrative bronze-nut coefficient of 0.15; it does not identify this asset's material or coefficient.

The current fixture held a 50 N axial load, rotated about 7 degrees under a brief 0.05 Nm pulse, and held again without touching the bench. An otherwise identical control with zero thread friction backdrove before reaching the bench. These results establish limited component behavior only. Real clamp contacts, robot handle operation, unloaded bearing drag, sensitivity to assumed parameters and complete gripper service still need validation.

`mechkit.py` is the repository's standard mechanism kit, originally from the heat-shrink-lug task. `closedloop.py` is the shared Arena demonstration helper. Neither helper is modified here.

The candidate's real service procedure comes from [SCHUNK's GWB operating manual](https://d16vz4puxlsxm1.cloudfront.net/asset/076200133045-Prod/document_tjvdlc511t38nfv12jd2uei35c/GWB%20Operating%20Manual.pdf), sections 5.3 and 6.4–6.6. Actual service contacts, complete replacement mechanics, novelty and full feasibility remain unresolved.
