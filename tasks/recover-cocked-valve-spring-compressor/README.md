# Valve-spring recovery feasibility prototype

Not validated or ready for submission. The concept requires a real-size cylinder head, a loaded valve spring, physical compressor engagement, controlled screw release, and spring extraction. No demo score has been established.

The mechanism helper is adapted unchanged from the shared open-source mechkit used by heat-shrink-lug. The SimReady loader is adapted from the open-source cutters-off-pegboard loader.
