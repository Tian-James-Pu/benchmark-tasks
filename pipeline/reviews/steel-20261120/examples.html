Examples

The examples shelf in examples/ holds 81 examples, each with a solver preset for every solver that runs it. Each clip shows the Steel preset, coupled with another solver where the scene has cloth, sand or particles. Hover a card to play its clip (on a phone, the card in the middle of the screen plays); open it for the presets and code.

Run one from examples/ with uv run shelf play <name> (run is the same command), add--solver <preset> for another preset, or start uv run shelf play with no name to browse them. Setup is in the examples README.

Clips recorded on an NVIDIA RTX PRO 6000 Blackwell.
